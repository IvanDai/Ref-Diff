# Local Datasets

Generated datasets are local artifacts and are not committed to Git.

RID2026 files belong in `datasets/rid2026/`:

```text
datasets/rid2026/rid2026_smoke.h5
datasets/rid2026/rid2026.h5
```

The smoke and full generation commands are documented in
`experiments/00_generate_rid2026/README.md`. The full uncompressed signal
arrays require approximately 39 GiB, plus channel parameters and temporary
write space.
